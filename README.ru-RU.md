# Cities: Skylines 2 — патчер для macOS / Wine

Исправляет вылеты и включает Paradox Mods для **Cities: Skylines 2**, запущенной под CrossOver на macOS.

Протестировано: **CrossOver 26 · Игра v1.5.8f1–v1.6.0f1 · Apple Silicon (M3 Pro → M5 Max)**

---

## Как пользоваться

Откройте Терминал, вставьте эту команду, нажмите Enter:

```bash
git clone https://github.com/alien-agent/cs2-macos-patcher && cd cs2-macos-patcher && ./patch.py
```

`patch.py` — единый **пошаговый интерактивный** инструмент. Он проведёт вас через все шаги:

1. **Находит игру** автоматически во всех бутылках CrossOver — включая пользовательскую папку бутылок, заданную в настройках CrossOver, — и показывает, пропатчена ли она уже
2. **Сначала показывает предпросмотр изменений** (пробный запуск, который ничего не записывает), а затем просит подтверждение
3. **Применяет все исправления** — запуск, ассеты, меню паузы, привязка сетей, Paradox Mods — и сохраняет резервные копии оригиналов в `*.bak`
4. При необходимости автоматически устанавливает dotnet через Homebrew

> **Нет dotnet?** Не проблема — патчер установит его за вас. Вам нужен только [Homebrew](https://brew.sh).
>
> Если dotnet уже установлен, патчер проверит, что им можно собрать исправления (SDK 9 или новее),
> и установит актуальный SDK через Homebrew, если ваш слишком старый (например, оставшийся .NET 6).

### После обновления игры

Запустите `./patch.py` снова и выберите Patch. И предпросмотр, и патчер определяют уже
пропатченные файлы и пропускают их, а затем применяют новые исправления к обновлённым DLL —
повторный запуск всегда безопасен.

### Игра не находится автоматически?

Укажите папку Managed напрямую:

```bash
./patch.py "/path/to/Cities2_Data/Managed"
```

Обычно папка Managed находится внутри бутылки CrossOver:

```
~/Library/Application Support/CrossOver/Bottles/<bottle-name>/drive_c/
  Program Files (x86)/.../Cities2_Data/Managed
```

### Ошибка лаунчера «exit code null» после обновления CrossOver (26.2+)

В Wine из CrossOver 26.2 изменился поиск исполняемых файлов, из-за чего лаунчер Paradox больше не
может запустить `Cities2.exe` — каждый запуск мгновенно падает с сообщением *«The game appears to
have crashed or terminated unexpectedly (exit code null)»*, даже на корректно пропатченной
установке (в логах лаунчера: `spawn Cities2.exe ENOENT`).

Патчер исправляет это автоматически при применении исправлений, добавляя папку игры в
пользовательский `PATH` бутылки (`HKCU\Environment` внутри бутылки). После патча **полностью
закройте и заново запустите Steam в бутылке**, чтобы лаунчер подхватил новое окружение.

### Восстановление оригинальных DLL

Запустите `./patch.py` и выберите **Restore original files** — все файлы `*.bak` будут скопированы
обратно поверх своих DLL.

Предпочитаете сделать это вручную? Резервные копии — это обычные копии файлов:

```bash
cd "<path-to>/Cities2_Data/Managed"
cp Backtrace.Unity.dll.bak Backtrace.Unity.dll
cp Colossal.IO.dll.bak Colossal.IO.dll
cp Colossal.IO.AssetDatabase.dll.bak Colossal.IO.AssetDatabase.dll
cp Game.dll.bak Game.dll
cp PDX.SDK.dll.bak PDX.SDK.dll
```

## Настройки CrossOver для лучшей производительности

Моя личная рекомендация для лучшей графики/производительности на CrossOver 26:

| Настройка                       | Значение             | Примечания                                                                                                                                                                                          |
|---------------------------------|----------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Graphics**                    | **D3DMetal**         | CS2 использует DirectX 12. D3DMetal (из Apple Game Porting Toolkit) — единственный транслятор с полноценной поддержкой DX12. DXVK и wined3d медленнее или сломаны для DX12. DXMT работает только с DX11 — не используйте его. |
| **Synchronization**             | **MSync**            | Синхронизация на семафорах Mach. Подтверждено, что для CS2 она лучше ESync.                                                                                                                          |
| **DLSS (powered by MetalFX)**   | **Включено**         | Новое в CrossOver 26. Требует, чтобы DLSS был также включён внутри игры. Заметный прирост FPS на Apple Silicon.                                                                                      |
| **High Resolution Mode**        | **Включено**         | Отключает удвоение пикселей — корректное поведение на дисплеях Retina.                                                                                                                              |
| **Windows version**             | **Windows 10 или 11** | Не используйте XP или 7 — они ломают возможности .NET-рантайма, на которые опирается игра.                                                                                                          |
| **AVX**                         | **Включено**         | CrossOver 25+ открывает игре AVX через `ROSETTA_ADVERTISE_AVX=1`. Повышает производительность на Apple Silicon под Rosetta.                                                                          |

> **macOS Tahoe (26)** даёт лучшую поддержку Metal 4 и все преимущества DLSS/MetalFX. На macOS
> Sequoia (15.x) часть возможностей Metal 4 недоступна.

## Настройки графики в самой игре

Эти настройки сильнее всего влияют на производительность внутри CS2.

**Основные настройки:**

| Настройка                  | Значение                                                                | Примечания                                                 |
|----------------------------|-------------------------------------------------------------------------|------------------------------------------------------------|
| **Display Mode**           | **Fullscreen Windowed**                                                 | Быстрее, чем Exclusive Fullscreen                          |
| **Resolution**             | **1080p или 1440p**                                                     | Не используйте родное разрешение Retina — оно убивает производительность |
| **VSync**                  | **Отключено**                                                           |                                                            |
| **Performance preference** | **Frame rate**                                                          |                                                            |
| **Dynamic resolution**     | **DLSS Balanced** (если MetalFX включён выше), иначе **FSR Quality**    |                                                            |
| **Depth of Field**         | **Отключено**                                                           | Один из самых тяжёлых эффектов в CS2                       |
| **Motion Blur**            | **Отключено**                                                           | Приятный прирост производительности бесплатно              |
