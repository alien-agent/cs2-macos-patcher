# Cities: Skylines 2 — патчер для macOS / Wine

Усуває збої та забезпечує роботу Paradox Mods у **Cities: Skylines 2**, запущеній через CrossOver на macOS.

Перевірено: **CrossOver 26 · Гра v1.5.8f1–v1.6.0f1 · Apple Silicon (M3 Pro → M5 Max)**

---

## Як користуватися

Відкрийте Термінал, вставте цю команду й натисніть Enter:

```bash
git clone https://github.com/alien-agent/cs2-macos-patcher && cd cs2-macos-patcher && ./patch.py
```

`patch.py` — це **інтерактивний інструмент із покроковими підказками**. Він:

1. **Автоматично знаходить гру** в усіх контейнерах (bottles) CrossOver — зокрема в нестандартній теці контейнерів, заданій у налаштуваннях CrossOver, — і показує, чи вже застосовано виправлення
2. **Спочатку показує майбутні зміни** (пробний запуск без запису файлів), а потім запитує підтвердження
3. **Застосовує всі виправлення** — запуск гри, ресурси, меню паузи, прив'язування мереж, Paradox Mods — і зберігає резервні копії оригіналів у `*.bak`
4. За потреби автоматично встановлює dotnet через Homebrew

> **Немає dotnet?** Не проблема — патчер встановить його автоматично. Потрібен лише
> [Homebrew](https://brew.sh).
>
> Якщо dotnet уже встановлено, патчер перевіряє, чи він може зібрати виправлення (потрібен
> SDK версії 9 або новішої), і за потреби встановлює актуальний SDK через Homebrew,
> якщо наявний застарів (наприклад, залишився .NET 6).

### Після оновлення гри

Повторно запустіть `./patch.py` і виберіть **Patch**. Попередній перегляд і сам патчер
розпізнають уже виправлені файли та пропускають їх, а до оновлених DLL застосовують
потрібні виправлення — повторний запуск завжди безпечний.

Після оновлення самого **патчера** (нова версія цього репозиторію, гра не змінилася)
спочатку виберіть **Restore original files**, а потім **Patch**. Звичайний повторний
запуск залишає наявні виправлення в тому вигляді, у якому їх застосувала попередня версія;
Restore → Patch заново застосовує кожне виправлення в його поточному вигляді.

### Примітка щодо оновлення: моди, які знову з'являються після видалення

Старі версії цього патчера та патчери, на яких він базується і які містять FIX 6, можуть
залишати на диску видалені моди, їхні попередні версії та теки `.downloading`. Оновіть
патчер, виберіть **Restore original files**, знову запустіть `./patch.py` і виберіть
**Patch**, як описано вище. Зробіть це, навіть якщо інструмент показує **Already patched**:
цей статус розпізнає виправлені DLL, але не перевіряє, яка версія патчера їх змінила.

Явний вибір **Re-Patch** також усуває саме цю помилку видалення без попереднього
відновлення оригіналів, зберігаючи наявні резервні копії. Restore → Patch залишається
рекомендованим способом оновлення, оскільки також оновлює старі варіанти інших виправлень.

Видалення все ще має відоме обмеження: якщо інший процес утримує файл мода відкритим,
SDK може без повідомлення про помилку залишити цей файл і його теку, видаливши решту
файлів. Завершіть процес, який утримує файл відкритим, і повторіть видалення; це
виправлення не забезпечує надійного повідомлення про помилки в такому випадку.

### Не вдається знайти гру автоматично?

Укажіть теку Managed безпосередньо:

```bash
./patch.py "/path/to/Cities2_Data/Managed"
```

Тека Managed зазвичай розташована всередині контейнера CrossOver:

```
~/Library/Application Support/CrossOver/Bottles/<bottle-name>/drive_c/
  Program Files (x86)/.../Cities2_Data/Managed
```

### Помилка лаунчера «exit code null» після оновлення CrossOver (26.2+)

У Wine з CrossOver 26.2 змінився пошук виконуваних файлів, через що лаунчер Paradox
більше не може запустити `Cities2.exe` — кожен запуск одразу завершується помилкою
*«The game appears to have crashed or terminated unexpectedly (exit code null)»*, навіть
якщо всі виправлення застосовано правильно (у журналах лаунчера: `spawn Cities2.exe ENOENT`).

Патчер автоматично усуває цю проблему під час застосування виправлень, додаючи теку гри
до користувацької змінної `PATH` (`HKCU\Environment`) у контейнері. Після застосування
виправлень **повністю закрийте й знову запустіть Steam у контейнері**, щоб лаунчер
отримав оновлене середовище.

### Відновлення оригінальних DLL

Запустіть `./patch.py` і виберіть **Restore original files** — кожен файл `*.bak` буде
скопійовано поверх відповідної DLL.

Хочете зробити це вручну? Резервні копії — це звичайні копії файлів:

```bash
cd "<path-to>/Cities2_Data/Managed"
cp Backtrace.Unity.dll.bak Backtrace.Unity.dll
cp Colossal.IO.dll.bak Colossal.IO.dll
cp Colossal.IO.AssetDatabase.dll.bak Colossal.IO.AssetDatabase.dll
cp Game.dll.bak Game.dll
cp PDX.SDK.dll.bak PDX.SDK.dll
```

## Налаштування CrossOver для найкращої продуктивності

Мої рекомендації щодо графіки та продуктивності в CrossOver 26:

| Налаштування | Значення | Примітки |
|---|---|---|
| **Graphics** | **D3DMetal** | CS2 використовує DirectX 12. D3DMetal (з Apple Game Porting Toolkit) — єдиний транслятор, який належно підтримує DX12. DXVK і wined3d повільніші або не працюють із DX12. DXMT підтримує лише DX11 — не використовуйте його. |
| **Synchronization** | **MSync** | Синхронізація на основі семафорів Mach. Підтверджено кращу продуктивність у CS2 порівняно з ESync та FSync. |
| **DLSS (powered by MetalFX)** | **Enabled** | З'явилося у CrossOver 26. DLSS також потрібно ввімкнути в самій грі. Значний приріст FPS на Apple Silicon. |
| **High Resolution Mode** | **On** | Вимикає подвоєння пікселів — правильна поведінка на дисплеях Retina. |
| **Windows version** | **Windows 10 або 11** | Не використовуйте XP або 7 — вони порушують роботу можливостей середовища .NET, потрібних грі. |
| **AVX** | **Enabled** | CrossOver 25+ надає грі доступ до AVX через `ROSETTA_ADVERTISE_AVX=1`. Покращує продуктивність на Apple Silicon під Rosetta. |

> **macOS Tahoe (26)** забезпечує найкращу підтримку Metal 4 і всі переваги DLSS/MetalFX.
> У macOS Sequoia (15.x) деякі можливості Metal 4 недоступні.

## Налаштування графіки в грі

Ці налаштування найбільше впливають на продуктивність самої CS2.

**Основні налаштування:**

| Налаштування | Значення | Примітки |
|---|---|---|
| **Display Mode** | **Fullscreen Windowed** | Швидше за Exclusive Fullscreen. |
| **Resolution** | **1080p або 1440p** | Не використовуйте рідну роздільну здатність Retina — вона різко знижує продуктивність. |
| **VSync** | **Disabled** | |
| **Performance preference** | **Frame rate** | |
| **Dynamic resolution** | **DLSS Balanced** (якщо вище ввімкнено MetalFX), інакше **FSR Quality** | |
| **Depth of Field** | **Disabled** | Один із найвимогливіших ефектів у CS2. |
| **Motion Blur** | **Disabled** | Простий спосіб підвищити продуктивність без додаткових витрат. |

## Подяки

Цей патчер спирається на роботу:

- **[alexqzd/cs2-crossover-patcher](https://github.com/alexqzd/cs2-crossover-patcher)** —
  оригінальний патчер для CrossOver та базові виправлення для `Colossal.IO.dll`,
  `Colossal.IO.AssetDatabase.dll` і Paradox Mods.
- **[icetear/cs2-net-snap-fix](https://github.com/icetear/cs2-net-snap-fix)** —
  дослідження першопричини помилки прив'язування піднятих мереж (Rosetta неправильно
  компілює SIMD-код Unity Burst), на якому ґрунтується відповідне виправлення цього патчера.

Дякую обом авторам за те, що першими розібралися з цими проблемами.
